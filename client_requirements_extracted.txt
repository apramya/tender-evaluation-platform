Final  Internship  Project  
AI-Based  Tender  Evaluation  &  Eligibility  Analysis  
Platform
 
(For  Government  of  Karnataka  Procurement  Systems)  
 
Problem  Statement  
Karostartup,  in  collaboration  with  the  Government  of  Karnataka,  is  building  an  intelligent  system  
to
 
automate
 
and
 
standardize
 
the
 
evaluation
 
of
 
government
 
tenders.
 
Government  tenders  contain  detailed  eligibility  criteria  spanning:  
●  Technical  requirements  ●  Financial  thresholds  ●  Compliance  conditions  ●  Mandatory  certifications  and  documents  
These  criteria  are  typically:  
●  Written  in  complex,  legal  language  ●  Spread  across  multiple  pages  ●  Difficult  to  interpret  consistently  
On  the  other  side,  bidders  submit  documents  in  highly  inconsistent  formats:  
●  Typed  PDFs  ●  Scanned  documents  ●  Word  files  ●  Images  and  photographs  
Currently,  evaluation  is  performed  manually  by  procurement  officers.  This  leads  to:  
●  Significant  time  consumption  ●  Inconsistent  decision-making  ●  High  risk  of  oversight  ●  Limited  auditability  
--- PAGE 2 ---
 
Karostartup  aims  to  solve  this  by  building  an  AI-powered  system  that  can  understand,  
evaluate,
 
and
 
explain
 
tender
 
eligibility
 
decisions
 
in
 
a
 
reliable
 
and
 
auditable
 
manner
.
 
 
Objective  
Design  and  build  a  system  that  can:  
1.  Understand  Tender  Documents  
●  Automatically  extract  eligibility  criteria  ●  Classify  them  into:  ○  Technical  ○  Financial  ○  Compliance  ●  Identify  mandatory  vs  optional  conditions  ●  Represent  criteria  in  a  structured  format  
 
2.  Process  Bidder  Submissions  
●  Ingest  and  process  multiple  document  formats:  ○  PDFs  (typed  and  scanned)  ○  Word  documents  ○  Images  /  photographs  ●  Extract  relevant  information  such  as:  ○  Turnover  values  ○  Certifications  ○  Project  history  ○  Registrations  ●  Handle  inconsistencies  in  formatting  and  representation  
 
3.  Evaluate  Bidders  
●  Compare  extracted  bidder  information  against  tender  criteria  ●  Assign  one  of  the  following  outcomes:  ○  Eligible  ○  Not  Eligible  ○  Needs  Manual  Review  
--- PAGE 3 ---
 
 
4.  Generate  Explainable  Results  
For  every  decision,  the  system  must  clearly  specify:  
●  The  criterion  being  evaluated  ●  The  source  document  used  ●  The  extracted  value  ●  The  reasoning  behind  the  decision  
Ambiguous  or  low-confidence  cases  must  be  flagged  for  human  review ,  not  rejected  
automatically.
 
 
System  Requirements  
The  solution  must:  
●  Provide  criterion-level  explainability  ●  Maintain  a  complete  audit  trail  of  decisions  ●  Support  scanned  and  image-based  documents  (OCR  required)  ●  Handle  uncertain  or  missing  data  gracefully  ●  Be  suitable  for  real-world  government  workflows  
 
Expected  Solution  
Interns  are  expected  to  design  and  implement  a  system  with  the  following  components:  
1.  Document  Understanding  Layer  
●  OCR  pipeline  for  scanned  documents  ●  Text  extraction  from  PDFs  and  Word  files  ●  Table  and  structured  data  parsing  
 
2.  Criteria  Extraction  Engine  
●  NLP  /  LLM-based  extraction  of  eligibility  conditions  ●  Classification  into  structured  rules  
--- PAGE 4 ---
 
 
3.  Information  Extraction  Engine  
●  Map  bidder  documents  to  required  fields  ●  Normalize  values  across  formats  
 
4.  Evaluation  Engine  
●  Rule-based  +  AI-assisted  matching  ●  Confidence  scoring  for  each  criterion  ●  Decision  classification  (Eligible  /  Not  Eligible  /  Review)  
 
5.  Explainability  &  Audit  Layer  
●  Evidence-backed  reasoning  for  every  decision  ●  Traceability  to  source  documents  ●  Structured  evaluation  logs  
 
6.  User  Interface  (Minimal  but  Functional)  
●  Upload  tender  document  ●  Upload  multiple  bidder  submissions  ●  Display:  ○  Extracted  criteria  ○  Bidder-wise  evaluation  ○  Supporting  evidence  ●  Export  consolidated  evaluation  report  
 
Deployment  Requirement  
The  complete  solution  must  be:  
●  Deployed  on  Render  ●  Accessible  via  a  live  URL  ●  Capable  of  handling:  ○  File  uploads  
--- PAGE 5 ---
 
○  Backend  processing  ○  Result  visualization  
 
Illustrative  Example  
Given  a  tender  requiring:  
●  Minimum  turnover  of  ₹5  crore  ●  At  least  3  similar  projects  in  the  last  5  years  ●  Valid  GST  registration  ●  ISO  9001  certification  
The  system  should:  
●  Extract  these  criteria  ●  Evaluate  all  bidders  ●  Output:  ○  Eligible  bidders  with  evidence  ○  Ineligible  bidders  with  exact  failure  reasons  ○  Ambiguous  cases  flagged  due  to  unclear  or  incomplete  data  
 
Key  Challenges  to  Address  
●  Handling  low-quality  scanned  documents  ●  Interpreting  ambiguous  legal  language  ●  Managing  incomplete  or  inconsistent  data  ●  Ensuring  high  explainability  and  trust  ●  Maintaining  auditability  for  government  compliance  
 
Deliverable  
A  working,  deployed  system  that  demonstrates:  
●  End-to-end  tender  evaluation  workflow  ●  Explainable,  criterion-level  decisions  ●  Robust  handling  of  real-world  document  variability
